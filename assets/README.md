# Assets

Code-drawn SVG art for the first playable. Licence: CC BY-SA 4.0 ([LICENSE.md](LICENSE.md)).
Do not edit the SVGs by hand: they are generated by `art/src/*.py` (see [art/README.md](../art/README.md)).

| Folder | What | Metadata |
|---|---|---|
| `toys/soldier/` | The plastic army soldier as cutout parts, 4 faces, 3-layer jetpack | `rig.json`, `poses.json` |
| `weapons/` | 8 launch weapons as toy props, plus the rocket projectile | `weapons.json` |
| `fx/` | Muzzle flash, thrust, smoke ring, tracer, frag blast, the pop | `fx.json` |
| `maps/bedroom/` | Bedroom kit: playable props, floor, muted backdrop | `kit.json` |
| `pickups/` | Health pack and battery pack | `pickups.json` |

## Scale

| Unit | Value |
|---|---|
| Author px | 4 per game px at a 720 px tall screen |
| World unit `u` | 8 author px (a toy is about 45 u, 360 px) |
| Bedroom kit | 30 author px per cm: the soldier is a 12 cm toy, the room 240 cm tall |

Import scale in Godot: 0.25 for a 720 px tall view, 0.375 for 1080. Every file's pixel size
equals its viewBox, and every point in the json files is in px from the file's top-left, so
multiply by the import scale.

All files use only what Godot's SVG importer (ThorVG) renders the same as librsvg: paths,
basic shapes, linear and radial gradients, clip paths, opacity. No filters, text, masks or
blend modes. `python3 art/tools/check.py` enforces this and compares Godot's raster of every
file against librsvg.

## The soldier rig (`toys/soldier/rig.json`)

- Each part has `file`, `pivot` (the joint, px from the file's top-left), `parent`, `pos` (where
  the pivot sits in the parent's frame), `rot` and `z` (draw order). The root is the ground
  point between the feet. Rest pose faces right; mirror the root on x to face left.
- `far_*` limbs carry a `modulate` to darken them: they are the same files as the near limbs.
- `face` is a slot: swap the file for `determined`, `cocky`, `hurt` or `shocked`.
- Team: `jetpack_team.svg` is greyscale, tint it with the team colour (modulate), or use the baked
  `jetpack_team_<team>.svg`, which also carry a team pattern (plain, stripes, dots, chevrons) for
  colour-blind players. The game tints the greyscale layer and lays `jetpack_pattern_<kind>.svg`
  over it, so any palette keeps its pattern. The thin team outline is a shader on the composed toy (a `CanvasGroup`
  with an outline shader works; `art/tools/godot_frame.gd` has one).
- Sockets: `weapon_grip` (trigger hand, near forearm, drawn over the weapon at z 14),
  `weapon_support` (far forearm), `thrust` (two nozzles, pointing down), `name_tag`.
- `poses.json`: stand, run, fly, aim. `grip_at` and `aim` place the weapon in the root frame;
  the arms reach its grip and support points by two-bone IK (`art/tools/compose.py`,
  `two_bone`), which the game can copy.

## Weapons (`weapons/weapons.json`)

Each weapon faces right with `grip`, `muzzle`, optional `support` (two-handed) and `hands`.
Colours avoid the team hues so a gun never reads as a team mark; every gun has an orange toy
safety tip. `rocket` is the launcher's projectile, `exhaust` is where its flame goes.

## Effects (`fx/fx.json`)

`blend: normal` files are the hot shapes, drawn as is. `blend: add` files (`*_glow`, `tracer`) are
light on a transparent ground: use `CanvasItemMaterial` with `BLEND_MODE_ADD`. Origins: a flash
starts at the muzzle pointing right, a flame at the nozzle pointing down, a tracer's origin is
its head. The frag blast is drawn at about 0.45 of the T-63 radius (125 u); scale to taste.
The soldier's pop is the rig's own parts flying apart, plus `pop_snap` at each joint,
`pop_burst` and `pop_text`.

## Bedroom kit (`maps/bedroom/kit.json`)

- `kind`: `prop` and `tile` are playable (saturated, inked like the toys), `backdrop` is muted
  and never collides, `light` is added.
- `origin`: a prop's floor contact (bottom-left), the fan's ceiling mount, the shelf plank's
  top-left.
- `collision`: polygons; `solid` blocks, `platform` is stood on from above. The bed is open
  under its rail, so a toy can walk underneath. The bookshelf's dark back panel is not solid.
- `floor`, `skirting` tile horizontally; `wall_tile` tiles both ways.
- Props cast a wall shadow in the mock frame: a copy of the sprite, black at 16% alpha, offset
  (70, -10) author px. No blur needed.

## In the game

Every SVG here is imported as "keep" (its `.import` file says so): the game rasters them itself
into sheets at load, see [docs/art-in-game.md](../docs/art-in-game.md). Add a new SVG with the
same three-line `.import` file.
